# Configuration

Statir works without any configuration at all, but a few optional settings let you fine-tune the output.

## Site-wide configuration — `_config.yml`

Place a `_config.yml` file at the root of your repository. All keys are optional.

```yaml
title: My Awesome Docs
description: The official documentation for My Awesome Project.
baseUrl: ""
```

| Key | Default | Description |
|-----|---------|-------------|
| `title` | First `#` heading in `README.md` | Displayed in the browser tab and site header |
| `description` | `Style-based site generated by Statir` | Used in `<meta name="description">` and Open Graph tags |
| `baseUrl` | `""` | Prefix prepended to all internal links (useful for sub-path hosting) |

> **Note:** Statir uses a minimal YAML parser. Only simple `key: value` pairs at the top level are supported — no nested objects or multi-line values.

## Per-page front matter

Add a YAML block between `---` markers at the very top of any `.md` file to control how that individual page is rendered.

```yaml
---
title: My Custom Page Title
description: A short summary shown in search results and link previews.
date: 2026-01-15
layout: docs
permalink: /my-custom-url/
---
```

### Supported front-matter keys

| Key | Description |
|-----|-------------|
| `title` | Overrides the page title derived from the first `# heading` |
| `description` | Short summary for meta tags |
| `date` | Publication date (ISO 8601). Shown in blog/cleanpack layouts |
| `layout` | Force a specific layout for this page (`classic`, `sidebar`, `bare`) |
| `permalink` | Custom output path (e.g. `/docs/intro/`) |

## Logo

Drop an image called `logo.png` (or `logo.jpg` / `logo.svg`) inside an `assets/` folder at the repo root:

```
my-repo/
└── assets/
    └── logo.png   ← auto-discovered and shown in the header
```

Statir will embed it in the site header automatically — no config needed.

## Private repositories

If your repository is private, enter a **Personal Access Token** (PAT) in the *Token* field when publishing. Use a fine-grained token with read-only access to the repository — never your account password.
